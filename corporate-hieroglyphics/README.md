# Corporate Hieroglyphics

A word-definition atlas.

Tech people, product people, and “AI founders” keep carving the same shapes into READMEs and calling it communication. This atlas translates those shapes back into English a tired human can read without a decoder ring.

This folder is a **split-ready GitHub repo**. It was built beside [Anarchy LLM](https://github.com/anastaysia94-sudo/Anarchy-LLM) because the coding session that wrote it is only allowed to push to that project. To make this its own GitHub repository named **Corporate-Hieroglyphics**, see [HOW-TO-MAKE-THIS-ITS-OWN-GITHUB-REPO.md](HOW-TO-MAKE-THIS-ITS-OWN-GITHUB-REPO.md).

## House rules

1. Prefer a normal sentence. If a jargon word is the only honest word, keep it and define it.
2. A definition that still needs a second jargon word is a failed definition.
3. “Said like a human” comes first. “Why people hide behind it” comes second. Project-specific notes come last.
4. Do not invent extra mystery. The point is less mystery.

## Why this exists

Anarchy LLM was explained in engineer-voice. The follow-up request was: say that again so a person who does not live in GitHub can follow it, and park every unavoidable technical word in an atlas named **Corporate Hieroglyphics**.

That is this.
