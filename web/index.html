Two historically inspired interaction styles, rebuilt around one non-negotiable rule: the model does not gain permission to invent facts, fake tools, or pretend uncertainty vanished because a persona is entertaining.

DAN Mode

A candid, irreverent, highly direct single-voice mode inspired by the historical DAN prompt family. It preserves directness and personality, not the old instruction to fabricate.

Villagers Mode

A routed specialist mode inspired by the historical stranded-survivors / isolated-village prompt pattern. Khan routes a request to the survivor with the strongest relevant expertise; Johnson is the fallback when nobody clearly fits.
